Điều khiển từ xa

Mở hai giao diện trên hai thiết bị. Máy trình chiếu quyết định nội dung đang hiển thị; máy người nói đọc lời dẫn và gửi lệnh chuyển trang.

Tạo một phiên trên máy đang nối với máy chiếu, sau đó mở liên kết ghép nối trên thiết bị người nói.

Chỉ gửi mã hoặc liên kết này cho người điều khiển. Mỗi phiên nhận một thiết bị điều khiển.

Thiết lập Firebase và GitHub Pages

Cấu hình một lần cho file HTML. Cả hai máy dùng cùng dự án Firebase.

  1. Tạo dự án tại Firebase Console, đăng ký ứng dụng Web.
  2. Trong Authentication → Sign-in method, bật Anonymous.
  3. Tạo Realtime Database. Sao chép đúng databaseURL và dùng bộ Rules bên dưới cho cơ sở dữ liệu dành riêng cho sổ tay này.
  4. Dán đối tượng firebaseConfig của ứng dụng Web vào ô dưới; cần apiKey, projectId, databaseURL, appId. Có thể dán cả đoạn const firebaseConfig = {...};.
  5. Nhấn Lưu cấu hình, rồi Tải HTML đã cấu hình. Đổi tên tệp thành index.html, đưa lên kho GitHub và bật Pages. Hai đường dẫn là ?view=display và ?view=presenter.

Chỉ nhập cấu hình Web, không nhập khóa service account hoặc khóa quản trị. Chế độ đọc tại chỗ vẫn dùng được khi không có mạng; điều khiển từ xa cần Internet.

Rules cần đặt trong Realtime Database

Bộ Rules này dành cho một database riêng: chặn liệt kê phiên, yêu cầu đăng nhập ẩn danh, chỉ máy trình chiếu ghi nội dung và thiết bị đã ghép nối gửi lệnh. Phiên có hiệu lực tối đa 6 giờ.

Nếu báo permission-denied, kiểm tra đúng Realtime Database và Rules. Nếu báo operation-not-allowed, bật Anonymous. Nếu dùng giới hạn API key, cho phép tên miền GitHub Pages của bạn và các API Firebase cần thiết.


Tài liệu Firebase: Web SDK · Anonymous Authentication · Database Rules.
